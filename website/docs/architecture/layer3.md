# Layer 3 (Interop)

## Bridge

- **Asset Transfer**: Cross-chain token transfers
- **Message Passing**: Generic message relay between chains
- **Verification**: Light client verification of remote chain state

## Governance

- **Proposals**: On-chain proposal submission
- **Voting**: Token-weighted voting mechanism
- **Execution**: Automatic execution of approved proposals

## Intents

- **Intent Matching**: Match user intents with solvers
- **Solver Network**: Decentralized solver infrastructure
- **Settlement**: On-chain settlement of intent matches

## Interop

- **Cross-Layer Communication**: Message passing between L1, L2, L3
- **Standard Interface**: Unified API for cross-chain operations
- **Atomic Execution**: Cross-chain atomic transactions

## Appchain SDK

- **Framework**: Build application-specific chains
- **Modules**: Reusable modules for common functionality
- **Customization**: Extend and modify chain behavior
